# RollercoinBot-AutoPlay

Welcome to **RollercoinBot-AutoPlay**! This bot is designed to automate gameplay for the [Rollercoin](https://rollercoin.com/) games, specifically **"Coinclick"** and **"Hamster Climber"**.

After setting up and starting the bot, you can sit back and let it collect points for you in these mini-games.

## Requirements

- **Resolution**: 1920x1080
- **Browser**: Google Chrome

> **Note**: The bot is tailored to work optimally at a resolution of 1920x1080 and using Google Chrome. Adjustments may be necessary for different settings.


## Troubleshooting

If you encounter any issues, please ensure:
- Your screen resolution is set to 1920x1080.
- You are using Google Chrome for the best compatibility.
- The game is fully visible and not obstructed by other windows.

If problems persist, feel free to contact me through GitHub.
